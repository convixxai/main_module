Deepgram vs AssemblyAI — STT Comparison Tool

Standalone, local-only page — nothing here talks to your Convixx backend. Audio and API keys go straight from your browser to Deepgram/AssemblyAI.
Getting trial keys (no credit card required, confirmed as of Sept 2026):
Deepgram: sign up at deepgram.com → Console → API Keys ($200 free credit, ~25k+ minutes of STT).
AssemblyAI: sign up at assemblyai.com → dashboard → API key ($50 free credit).
Keys are stored only in this browser's localStorage — never sent anywhere except directly to the provider you're testing.
Important asymmetry: Deepgram's /v1/listen call below is a single request (comparable to real transcription latency). AssemblyAI's file API is upload → submit job → poll until done, so its "total time" includes queueing overhead and is not a fair proxy for their real-time streaming latency. Use this tool for accuracy comparison (especially Hindi/Marathi) — for a true latency comparison, test each provider's real-time streaming API directly.
